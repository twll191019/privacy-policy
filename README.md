# Privacy Policy for hc-auto

Last updated: May 11, 2026

hc-auto is a private social media publishing integration with Facebook services.

## Information We Access

When you authorize this application through Facebook, the application may access basic account information and the Facebook Pages you manage, only for the purpose of connecting your Facebook account and publishing content that you create or schedule.

Depending on the permissions granted, the application may access:

- A list of Facebook Pages you manage
- Page access information required for publishing
- Content publishing permissions for selected Pages
- Basic engagement or insight information if enabled

## How We Use Information

We use the information only to:

- Authenticate your Facebook account
- Display the Facebook Pages you manage
- Publish posts that you create or schedule
- Maintain the connection with Facebook

## Data Sharing

We do not sell, rent, trade, or share Facebook user data with third parties.

## Data Storage

This application is used for private and self-hosted publishing.
